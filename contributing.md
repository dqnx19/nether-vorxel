# Contributing to vorxel.js

## Reporting Issues

| Email                                   | Github                                                                                         |
|-----------------------------------------|------------------------------------------------------------------------------------------------|
| Open your email client                  | go to [https://github.com/dqnx19/nether-js/issues](https://github.com/dqnx19/nether-js/issues) |
| Click to new email                      | Click to `new issue`                                                                           |
| To title write "bug report"             |To subject write "bug report"                                                                   |
| in description briefly describe the bug | in message content briefly describe the bug                                                    |
| Click to "create"                       | Click to "send"                                                                                | 

if it will be possible to contact you, you will be informed if your report is a bug or not and if yes you will be informed that it was fixed
