Use this code to create one element
```javascript
createElement({
    element: "",
    parent: ""
});
```

Use this code to create multiple elements:

```javascript
createElement([
    {
        element: "",
        parent: ""
    },
    {
        element: "",
        parent: ""
    }
]);
```

- `element` – HTML element name (e.g. `"div"`, `"span"`).
- `parent` – Parent element or CSS selector of the parent element.
