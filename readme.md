#  vorxel.js

## About the project
vorxel.js is a lightweight JavaScript framework that provides simple utility functions for common web development tasks.

It includes functions for things such as setting the page title or favicon, scrolling the page, manipulating HTML elements, and more.

The goal of vorxel.js is to make common JavaScript tasks easier by providing simple functions with clear and descriptive names.
